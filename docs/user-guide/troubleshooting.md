# 故障排查

[用户指南](README.md) · 上一篇：[隐私与已保存偏好](privacy.md) · 下一篇：[术语表](glossary.md)

从下面的症状开始。如果某个操作失败，在再次提交之前，先检查它是否已经生效，尤其是工单、上传或业务请求。

## 访问与登录

| 问题 | 可以尝试 |
| --- | --- |
| 网站打不开 | 检查你的组织提供的地址、你的连接，以及任何所需的内部网络访问。如果仍然不可用，请联系安装运维人员。 |
| **Invalid username or password** | 使用你的用户名，检查拼写和键盘输入，然后再试一次。没有密码恢复界面；如有需要，请联系账号管理员。 |
| **Username or email already registered** | 使用现有账号，或请管理员帮助识别它。 |
| **Local registration disabled** | 使用你组织的账号开通或公司登录流程。即使注册已禁用，注册链接仍可能可见。 |
| **User is inactive** 或 **User inactive or missing** | 询问账号管理员该账号是否已被禁用。 |
| 你被退回登录页或看到 **401 / Invalid token** | 重新登录。如果反复出现，请携带时间和错误联系运维人员。 |
| **403 / Admin required / Agent or admin required** | 你的角色不允许此操作。请管理员安排正确的访问权限。 |
| 功能或菜单缺失 | 它可能已被禁用，或能力信息加载失败。刷新一次，并请管理员检查 **插件与能力**。 |
| Admin 可以打开，但看板失败 | 客服可以在没有管理员报表访问权限的情况下使用工单和接管页面。打开 `/admin/handoffs` 或 `/admin/tickets` 进行客服工作。 |

## 对话与答案

| 问题 | 可以尝试 |
| --- | --- |
| 消息框被禁用 | 创建或选择一个会话。如果回复正在进行中，请等待它完成。 |
| 你看到 **发送失败 (Send failed)** 或连接错误 | 记下你尝试发送的消息。在重试前刷新并检查已保存的历史；请求可能已被接收。报告持续存在的错误。 |
| 助手一直停留在 **正在思考… (Thinking…)** | 留出响应时间后，刷新并重新打开会话。如果没有保存答案，请向支持报告时间和请求。 |
| 答案说信息不足 | 添加具体细节、提出组织支持的问题，或请求人工。知识库可能不包含该答案。 |
| 即使换种说法也缺少相关答案 | 请管理员核实源文档是最新的、已索引且可读。 |
| 答案不正确或过时 | 记录问题、答案和被引用的来源。告诉支持哪些内容与预期信息冲突。 |
| 没有引用按钮 | 澄清、业务回复和其他响应可能没有来源。微件也没有引用抽屉。 |
| AskFlow 忘记了之前的某个细节 | 在同一会话中重述它。每次回复只使用有限数量的较早上下文。 |
| 请求因过长或不受支持而被拒绝 | 将其缩短为相关事实。对于被错误阻止的普通请求，请将准确的错误发送给支持。 |
| 你看到 **429** 或限流消息 | 在重试前暂停，避免反复快速提交。 |
| 你看到 **500 / 502 / 503** | 服务或某个依赖项可能不可用。在重试前检查已保存的历史，如果问题持续存在，请联系运维人员。 |

## 订单、人工和工单

| 问题 | 可以尝试 |
| --- | --- |
| 订单查询已被受理但没有出现结果 | 刷新并重新打开同一会话。如果仍未解决，请让支持检查已保存的任务和业务连接。 |
| AskFlow 再次索要订单号 | 将完整请求和准确的订单号一起发送。如果它仍无法识别订单，请联系支持。 |
| 订单结果标记为 mock 或模拟 | 将其视为演示数据。请支持通过真实服务核实实际订单。 |
| 你想取消已受理的工作 | 联系支持，或使用你组织单独的任务管理界面。关闭浏览器或输入“cancel”并不保证取消。 |
| 没有人工响应 | 检查是否有排队或超时消息，刷新会话，并使用你组织的备用联系方式。检查是否创建了跟进工单。 |
| 客服收件箱为空 | 与管理员一起检查角色、团队成员资格和请求类型范围。 |
| **409 / Already claimed** | 可能有另一位客服人员认领了该条目。刷新并检查认领人。 |
| **Not your handoff** | 打开你认领的会话。只有认领人才能将其交还给 AI。 |
| 工单没有出现 | 刷新 **我的工单**，并确认你使用的是同一账号和渠道。检查是否存在同标题的未关闭工单。 |
| 已关闭的工单需要继续处理 | 携带其标题和创建时间联系支持。客户页面没有重新打开操作。 |
| 记录报告 **404 / not found** | 检查参考号、账号和功能可用性。该记录可能对此账号不可用，或已被移除。 |

## 知识与管理员控件

| 问题 | 可以尝试 |
| --- | --- |
| 上传报告 **Empty file** | 在文本编辑器中打开该文件，保存实际文本后再上传。 |
| 上传报告 **413 / file_too_large** | 将来源拆分为更小、连贯的文本文档，或询问运维人员配置的限制。 |
| PDF、Word 文件或扫描件给出糟糕的答案 | 将其内容转换为可读的 UTF-8 文本或 Markdown。当前解析器无法可靠提取那些文件格式。 |
| 文档一直处于待处理或索引中 | 等待后刷新。如果未变化，请让运维人员检查索引；避免反复上传副本。 |
| 文档失败或分块为零 | 检查来源是否包含可读文本。向运维人员询问处理错误和重建索引；网页没有重建索引按钮。 |
| 上传相同文件名创建了另一行 | 每次上传都会创建一份单独的文档。在检查应保留哪些内容后，安排移除过时副本。 |
| 版本比较不可用 | 需要至少两个保留的快照。**差异** 按钮被禁用是正常的；选择 **from** 和 **to** 以加载可用的比较。 |
| 生成的知识草稿只包含一个问题 | 这是当前从缺口到草稿的行为。创建一个包含已验证答案的新草稿；不要发布仅含问题的占位草稿。 |
| 操作似乎成功但列表没有变化 | 刷新并检查该行的实际状态。如果未变化，请记录该操作并报告，而不要假设成功。 |
| 出现 **422** 或验证消息 | 检查必填字段、允许的选项和长度。如果标准表单仍然失败，请报告准确的错误消息。 |
| 连接器测试返回错误 | 将结果和连接器名称交给运维人员。该按钮不发送自定义参数，可能不适合该连接器所需的输入。 |
| 某个设置没有编辑按钮 | 有些能力只有单独的管理界面。关于实际提供的控件，请参见 [管理](administration.md)。 |

## 访客与即时通讯渠道

如果嵌入式对话不再打开它以前的会话，浏览器会话可能已过期或丢失。请携带任何已保存的请求参考号联系网站的支持团队。清除浏览器数据可能会丢失对访客会话的本地访问，并且不会删除服务器记录。

如果即时通讯机器人不回答，请确认你使用的是组织配置的机器人，并发送一条简单的文本消息。如果仍然没有回复，请让渠道管理员检查送达。附件识别、出站回复和之后的后台更新是各自独立的能力；请参见 [其他对话方式](channels.md)。

## 清楚地报告问题

将以下内容发送给你组织的 AskFlow 支持联系人：

- 你使用的页面或渠道，以及你的账号角色。
- 你尝试做什么，以及你采取的步骤。
- 你期望什么，以及实际发生了什么。
- 准确的错误文本和大致时间，包括时区。
- 会话、工单、任务、文档或 Run ID（如果有）。
- 刷新是否改变了结果，以及它是否反复发生。

只有在有用时才包含截图，并移除无关的个人信息。绝不要在问题报告中发送密码、登录令牌或密钥。

普通用户应联系运营其服务的组织。正在调查软件缺陷的技术运维人员可以使用项目的 [问题跟踪器](https://github.com/RightCloudhub/AskFlow/issues)，并提供不暴露客户数据的复现步骤。
