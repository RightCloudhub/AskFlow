# 术语表

[用户指南](README.md) · 上一篇：[故障排查](troubleshooting.md)

| 术语 | 含义 |
| --- | --- |
| 账号角色（Account role） | 分配给某人的权限：客户、客服或管理员 |
| 管理员（Administrator / admin） | 被允许管理 AskFlow 内容、账号、设置和报表的人 |
| Agent | 在账号角色中指人工客服人员；在技术描述中有时指处理请求的自动软件 |
| AI / 助手（assistant） | 解释请求并帮助生成回复或安排操作的软件 |
| API | 软件与 AskFlow 通信的方式；普通用户无需直接调用它 |
| 审计日志（Audit log） | 管理操作或其他被跟踪操作的记录 |
| 渠道（Channel） | 联系支持的地方，例如主网站、嵌入式对话或即时通讯应用 |
| 分块（Chunk / 分块） | 为搜索准备的文档的一小段 |
| 引用（Citation / reference / 引用） | 支持答案的带编号来源段落 |
| 置信度（Confidence / 置信度） | 系统对答案支持程度的估计，不是正确性的保证 |
| 连接器（Connector / 连接器） | 与外部业务服务的已配置连接 |
| 会话（Conversation / 会话） | 已保存的消息往来 |
| 草稿（Draft / 草稿） | 尚未批准发布的知识内容提案 |
| 抽屉（Drawer） | 在页面侧边打开以显示详情的面板 |
| FAQ | 常见问题及其答案 |
| 功能 / 插件（Feature / plugin / 插件） | AskFlow 安装可以启用的可选部分 |
| 标记（Flag） | 关于处理请求时发生情况的简短诊断标签 |
| 代（Generation / Gen） | 文档的已索引修订号 |
| 接地（Grounding） | 检查检索到的信息是否支持答案 |
| 转人工（Handoff / 转人工 / 人工接管） | 将会话或责任转交给人工客服人员 |
| 索引（Indexing / 索引） | 准备文档文本以便 AskFlow 可以搜索它 |
| 意图（Intent / 意图） | 客户似乎在请求的帮助类型 |
| JSON | 用于技术细节和集成响应的结构化文本格式 |
| 知识库（Knowledge base / 知识库） | AskFlow 可以查阅的文档和已批准答案 |
| 知识缺口（Knowledge gap / 知识缺口） | 已记录的、缺乏足够知识覆盖的问题 |
| 语言模型（Language model / LLM） | 可以解释或生成语言的服务 |
| Markdown | 带有简单格式约定（如标题和列表）的纯文本 |
| Mock | 用于演示或测试的模拟数据 |
| 运维人员（Operator） | 负责安装、配置和运行服务的人 |
| 偏好（Preference） | 明确确认的选择，例如简要回复或首选语言 |
| Profile | 所选的一包已启用 AskFlow 功能 |
| 提示词（Prompt / 提示词） | 自动助手为特定目的使用的指令 |
| 拒答（Refusal / 拒答） | 说明 AskFlow 无法提供有支持的答案或满足请求的回复 |
| 回放（Replay / 回放） | 查看已保存的处理记录；它不会重复执行操作 |
| RAG | 检索增强生成：查找相关段落并用它们来回答 |
| 回滚（Rollback / 回滚） | 将较早的文档内容恢复为新的活动修订 |
| 路由（Route / 路由） | 响应方式：知识答案、工具、工单、人工支持或澄清 |
| 运行（Run / Run ID） | 处理一条消息的一次已记录尝试，以及用于查找它的标识符 |
| 服务任务（Service task） | 为处理和跟踪而保存的、超出一条即时回复的工作 |
| 会话期（Session） | 与已登录账号或浏览器访客关联的一段时间的访问 |
| 技能组（Skill group / 技能组） | 具有明确请求类型范围的客服团队 |
| SLA | 服务级别协议：处理支持请求的目标 |
| SSO | 单点登录：使用组织的登录系统 |
| 流式输出（Streaming） | 随着答案文本到达逐步显示 |
| 工单（Ticket / 工单） | 需要跟进的问题记录 |
| Token | 为模型输入或输出计数的一段文本；它不一定是一个词 |
| 微件（Widget） | 嵌入另一个网站的紧凑型支持对话窗口 |

关于状态的具体含义，请参见 [对话](chat.md)、[工单](tickets.md)、[知识](knowledge.md) 和 [报表](reports.md)。
