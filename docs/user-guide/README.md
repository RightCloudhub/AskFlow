# AskFlow 用户指南

AskFlow 是一个客户服务网站。你输入一个问题，它可以在你组织的文档中查找答案、查询已连接的业务信息、记录一个问题以便跟进，或者把对话转交给人工。

你不需要了解人工智能如何运作就能使用它。本指南从打开网站开始，用日常语言解释每一项任务。

## AskFlow 如何提供帮助

把 AskFlow 想象成一个带有参考资料库的服务台：

1. 你说明你需要什么。
2. AskFlow 要么搜索参考资料、使用已连接的服务、向你询问更多信息，要么安排跟进。
3. 你阅读答案，或跟进请求，直到得到结果。

**会话（conversation）** 是你往来的消息交流。**工单（ticket）** 是需要跟进的问题的独立记录。**服务任务（service task）** 是 AskFlow 保存并可能在后台执行的工作，例如查询订单。收到“某事已被受理”的消息，并不意味着该工作已经完成。

例如，“退货政策是什么？”是在询问信息。“请查一下我的订单”是在请求业务查询。“我需要人工帮助”是在请求人工支持。询问退款政策本身并不会发起退款。

## 阅读说明

当前界面主要为中文。本指南以中文给出实际标签，并在括号中附上英文含义，例如 **新建会话**。这并不意味着应用有英文界面切换开关。

像 **Admin → 知识文档** 这样的说明意思是：点击 **Admin**，然后在侧边菜单中选择 **知识文档**。*抽屉（drawer）* 是页面侧边打开的面板；使用其关闭按钮即可返回到下面的页面。

像 `/tickets` 这样的路径指的是你组织 AskFlow 网站上的页面。请保留你的组织提供的网址，只更改其域名之后的部分。它们不是独立的公共网站。

## 你的组织中可用的功能

本指南描述的是截至 **2026 年 10 月 4 日** 仓库的用户界面和已连接行为。各组织会选择启用哪些功能。某些菜单项可能不存在，某些可见页面需要客服或管理员账号。

基本的对话体验可以在没有连接语言模型服务的情况下运行，它使用文档中的段落。实际的订单结果需要与你的组织订单系统有可用的连接。人工支持需要有可用的客服人员。当前标准对话流程不会自动执行退款或发送任意客户通知。

你的组织提供网址、账号、支持的服务和支持安排。如果不确定哪些功能可用，请询问其 AskFlow 管理员。

## 如果你是第一次设置 AskFlow

在客户使用 AskFlow 之前，必须有人先安装和运行它。普通用户只需要网址，以及主工作区的账号。

如果尚不存在网站，请把 [安装快速开始](../../README.md#快速开始) 和 [部署检查清单](../../deploy/checklists/pilot-integration.md) 交给负责你组织软件的人。本地安装是试用环境；组织范围的服务需要自己的部署和配置。

关于逐步的本地设置和配置文件的说明，请参见 [配置指南](../configuration/README.md)。网站运行后，请使用 [管理员的首次使用引导](administration.md#准备新服务) 为客户做好准备。
