# 客服人员指南

[用户指南](README.md) · 上一篇：[你的工单](tickets.md) · 下一篇：[知识管理](knowledge.md)

本章面向回复客户的人员。在账号设置中，角色 `agent` 表示人工客服人员。它不同于自动 AI 助手。

## 首次值班之前

请让管理员为你安排 `agent` 或 `admin` 账号。普通客户账号不能认领会话或管理其他用户的工单。

客服人员还需要加入适当的 **技能组 (Skill group)** 才能看到新入队的会话。技能组规定一个团队处理哪些类型的请求。队列为空可能意味着你的账号没有匹配的技能组，而不是没有客户在等待。

打开 **Admin → 人工接管 (Human handoff)**，或访问 `/admin/handoffs`。如果你的角色无法访问一般管理入口页，可以直接打开此页面。

## 认领并回答会话

1. 在 **人工接管** 中找到排队中的条目。阅读其 **摘要 (Summary)** 和 **意图 (Request type)**。
2. 点击该条目的 **认领 (Claim)**。认领会将你记录为负责的客服人员。
3. 在 **接管工作台 (Handoff desk)** 中查看会话和认领人信息。
4. 阅读 **会话消息 (Conversation messages)**。将摘要作为引言，然后对照消息核实重要细节。
5. 在 **以座席身份回复… (Reply as staff…)** 中输入你的回复。
6. 点击 **发送座席回复 (Send staff reply)**。
7. 确认你的回复出现在消息列表中。

收件箱每 15 秒刷新一次，并且有 **刷新 (Refresh)** 按钮。已认领会话的消息也会定期刷新。客户的主对话页面可能需要刷新浏览器才能显示客服回复。

稍后点击收件箱中的某一行以打开其详情。认领之前，抽屉显示其摘要；正常的客服工作流会在认领成功后加载消息历史。

如果你看到 **Already claimed** 或冲突错误，请刷新收件箱。可能有另一位客服人员认领了同一请求。不要反复尝试认领他人的会话。

## 将会话交还给 AskFlow

1. 完成你的解释，并告诉客户接下来会发生什么。
2. 如有必要，关闭抽屉以返回收件箱。
3. 在你认领的会话上，点击 **交还 AI (Return to AI)**。
4. 确认它离开你认领的队列。

会话将再次可供自动回复。只有认领它的人才能使用此交还操作。交还会话不会将相关工单标记为已解决、撤销操作，也不证明客户的原始问题已解决。

标准接管页面没有单独的 **解决会话 (Resolve conversation)** 按钮。请使用可用的交还操作来恢复自动对话，并单独管理任何工单。

## 处理工单

打开 **Admin → 工单中心 (Ticket center)**，或访问 `/admin/tickets`。

1. 在工单表中识别问题。
2. 开始处理时点击 **处理中 (Processing)**。
3. 通过相关会话或你组织的常规支持流程进行调查和沟通。
4. 只有问题真正得到处理后，才点击 **已解决 (Resolved)**。

这些按钮会立即更改状态。标准工单中心界面显示标题、状态、优先级和类型，以及处理和已解决操作。它不包含工单描述编辑器、负责人选择器、优先级编辑器或客服评论串。如果需要更多细节或其他更新，请使用你组织的支持集成或询问管理员。

更改状态记录的是一个决定；它不会执行工单所描述的处理或业务操作。请让客户了解实际结果。

## 处理后台请求

客户可能会报告订单查询已被受理但从未完成。向他们询问会话详情和订单号，然后通过你组织的任务管理集成或技术支持联系人进行核查。

当前标准客服工作台不显示服务任务列表或任务接管按钮。认领会话和承担其后台任务的责任是两种不同的操作。接受任务交转的集成必须使用同一客服人员已为客户和会话认领的交转。

不要将已受理的查询、已认领的会话或新登记的工单描述为已完成的客户结果。特别地，登记工单的任务可能已完成，而工单本身仍未解决。

## 常见客服问题

| 问题 | 下一步 |
| --- | --- |
| 收件箱为空，但同事能看到请求 | 请管理员检查你的角色、组成员资格和该组的请求类型 |
| 认领失败并报冲突 | 刷新；检查是否有人已认领，或请求已超时 |
| 回复失败并提示 **Not your handoff** | 检查认领人；打开分配给你的会话 |
| **交还 AI** 失败 | 确认该条目仍由你认领，然后刷新 |
| 客户看不到回复 | 确认回复出现在已保存的历史中；请客户刷新并重新打开会话 |
| 客户要求退款或取消 | 使用组织批准的业务流程并确认实际结果 |

对于你无法解决的错误，请记录时间、会话或工单参考号，以及准确的错误文本，交给你的管理员。
