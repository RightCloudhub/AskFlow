# 快速上手

[用户指南](README.md) · 下一篇：[与 AskFlow 对话](chat.md)

## 开始之前

你需要一个网页浏览器、与你的组织 AskFlow 网站的连接，以及主工作区的账号。向邀请你的人询问网址和登录说明。有些组织要求访问其内部网络。

你不需要安装开发者工具、购买 AI 订阅或提供模型密钥就能提问。嵌入其他网站的聊天窗口可能允许你以访客身份开始；请参见 [其他对话方式](channels.md)。

## 登录

1. 打开你的组织给你的 AskFlow 网址。
2. 如果登录页面尚未打开，请访问该网站上的 `/login`。
3. 输入你的 **用户名 (Username)** 和 **密码 (Password)**。常规登录表单使用用户名，而不是电子邮件地址。
4. 点击 **登录 (Sign in)**。

登录成功后，会话工作区会打开。如果你的组织使用公司登录（也称为单点登录或 SSO），请遵循其提供的说明。标准登录页面没有 SSO 按钮。

## 如果允许注册，创建账号

1. 在登录页面点击 **没有账号？注册 (No account? Register)**。
2. 选择 3–64 个字符的用户名。
3. 输入你的电子邮件地址。
4. 选择 8–128 个字符的密码。
5. 点击 **注册并登录 (Register and sign in)**。

注册成功后会直接登录。如果用户名或电子邮件已被注册，请使用现有账号或联系管理员。如果注册已禁用，请向你组织询问获取访问权限的批准方式；注册链接可能仍然可见。

新账号通常具有普通用户角色。客服和管理员访问权限必须由负责安装的人安排。有些试用安装被配置为将第一个账号设为管理员，因此请遵循安装所有者的说明，而不要依赖此行为。

目前没有 **忘记密码** 或修改密码界面。如果你无法使用密码，请联系你组织的账号管理员。

## 提出第一个问题

1. 在左侧边栏点击 **新建会话 (New conversation)**。
2. 点击页面底部的消息框。
3. 输入关于你组织所提供服务的问题，例如：“我申请退货需要提供哪些信息？”
4. 点击 **发送 (Send)**，或按 **Enter**。使用 **Shift+Enter** 换行而不发送。
5. 等待回复。**正在思考…** 意思是 “Thinking…”。文本可能一点一点出现。
6. 阅读答案。如果你在答案下方看到 **查看引用 (View references)**，请点击该按钮阅读来源段落。

你的问题显示在 **我 (Me)** 下方。自动回答显示在 **助手 (Assistant)** 下方。人工回复显示在 **人工客服 (Human support)** 下方。

如果 AskFlow 要求提供更多细节，请在同一会话中回复。如果它说信息不足，请尝试更具体的问题或请求人工支持。即使网站运行正常，空的或不相关的知识库也可能导致拒答。

在你创建或选择会话之前，消息框不可用。在回复发送期间，它也暂时不可用。

## 熟悉界面

| 控件 | 作用 |
| --- | --- |
| **新建会话** | 开始一个独立会话 |
| 左侧边栏的会话列表 | 打开已保存的会话 |
| **工单 (Tickets)** | 打开你的跟进记录（如果已启用） |
| **Admin** | 打开管理区域；其功能需要相应权限 |
| **退出 (Sign out)** | 在此浏览器上退出登录 |

在窄屏幕上，侧边栏可能会折叠。使用侧边栏控件展开它，如果看不到会话列表，可以加宽浏览器窗口。

会话名称可能都从 **新会话 (New conversation)** 开始。标准页面不提供重命名、搜索或删除会话的功能。打开某个会话并查看其消息以确认它是什么。

## 稍后返回

在同一 AskFlow 安装上使用同一账号登录，并从侧边栏选择已保存的会话。如果最新的回复缺失，请刷新浏览器并再次选择该会话。

开始新会话会给你一个单独提问的地方。它不会删除较早的会话，也不会取消其中已受理的工作。

## 退出登录

完成后点击 **退出 (Sign out)**，尤其是在共享计算机上。退出登录不会删除你的消息、关闭你的工单或取消后台工作。

关于登录错误、按钮缺失或页面无法加载，请参见 [故障排查](troubleshooting.md)。
