# 隐私与已保存偏好

[用户指南](README.md) · 上一篇：[其他对话方式](channels.md) · 下一篇：[故障排查](troubleshooting.md)

你的组织运营其 AskFlow 安装，并决定它连接哪些服务以及如何处理客户记录。请就该组织的隐私声明、保留政策或个人数据请求联系该组织。

## 可能保存的内容

AskFlow 可以存储账号详情、会话消息、工单、接管记录、后台任务进度，以及管理或诊断记录。上传的知识文档也会被存储，用于回答问题。

会话历史让你可以返回较早的消息。客服可以阅读他们被授权处理的会话，管理员具有管理访问权限。不要假设与自动助手的对话对支持组织是隐藏的。

根据部署情况，请求的一部分和相关上下文可能会发送到已配置的模型提供商或业务服务。AskFlow 网站由私人运营本身并不意味着每个连接的服务都在本地运行。如果这影响你可以分享的内容，请询问管理员使用了哪些提供商。

## 分享支持所需的细节

包含相关的产品名称、订单参考、错误消息，以及发生了什么情况的描述。遵循你组织关于客户信息的规定。

不要将账号密码、一次性登录验证码、密钥或完整的支付卡信息粘贴到支持对话中。如果客服需要身份验证或包含敏感信息的文档，请使用批准的流程。

## 会话历史与已保存偏好是不同的

记住你在会话中刚刚说过的话，与保存供将来使用的偏好是不同的。较长的会话只使用有限数量的较早上下文，因此你可能需要重述重要细节。

AskFlow 还通过单独的已认证集成支持明确确认的偏好：

| 偏好 | 支持的选项 |
| --- | --- |
| 回复语言 | 简体中文或英文 |
| 回复详细程度 | 简要或详细 |
| 首选联系渠道 | 对话或电子邮件 |

标准 Web 应用当前没有偏好页面或控件来保存、更正或删除这些值。在普通对话中说“记住这个”不是创建已保存偏好的可靠方式。如果你的组织提供偏好管理界面，请使用它并检查其确认信息。

已保存偏好需要明确同意。默认保留期为 30 天；支持的范围为 1–90 天。过期或已删除的偏好会被排除在活动偏好使用之外。更改已保存的回复语言不会更改 Web 界面语言，选择电子邮件也不会设置电子邮件送达或承诺电子邮件通知。

偏好消费当前连接到后台任务处理，而不是每条回复的通用个性化设置。你当前的请求和已核实的业务信息优先于已存储的偏好。

系统没有提供标准客户页面来编辑已学习的事实或查看自动个人资料。

## 请求更正、副本或删除

联系你组织的支持或隐私联系人，并说明你想要更正、导出或移除什么。指明涉及的账号和渠道，并遵循他们的身份验证流程。

标准 Web 界面中没有客户数据导出、删除账号、删除会话或已保存偏好的控件。用户管理界面也不提供导出或删除按钮。经授权的运维人员对其中一些操作有单独的界面。

当前用户数据导出/删除操作涵盖与账号相关的会话、消息、工单和反馈记录。不应将它们表述为对每个存储项目的完整导出或擦除：较新的服务任务和记忆记录、接管和审计记录、备份以及外部服务都需要单独审查。请让组织确认实际完成的范围。

删除已保存偏好会停止其活动使用；它不会移除包含相同信息的较早会话消息。禁用账号、退出登录、清除浏览器存储、关闭工单和取消任务也是不同的操作，而不是数据删除的替代。

需要请求格式的运维人员，请参见技术文档 [客户偏好文档](../architecture/customer-preference-memory.md) 和 [API 指南](../../apps/api/README.md)。
