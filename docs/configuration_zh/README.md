# AskFlow 配置指南

配置告诉 AskFlow 在哪里保存其记录、提供哪些功能，以及如何连接到其他服务。本指南面向设置或管理安装的人，包括第一次进行配置的人。

使用现有网站的客户无需配置服务器。如果你只是想登录并提问，请从 [用户指南](../user-guide/README.md) 开始。

## 理解各个组成部分

| 组成部分 | 通俗含义 | 你是否需要立即使用它？ |
| --- | --- | --- |
| Web 应用 | 人们在浏览器中打开的页面 | 是，标准界面需要 |
| API/后端 | 处理请求的运行程序 | 是 |
| 数据库 | 存储账号、消息、工单和任务进度 | 是；试用时本地 SQLite 文件即可 |
| 上传的文件 | 用于回答的来源文档 | 添加你自己已批准的内容 |
| 搜索索引 | 为搜索准备的文档文本副本 | 在你上传/索引文档时创建 |
| 语言模型服务 | 用于生成答案的可选服务 | 否；基本的抽取式答案无需它即可运行 |
| 嵌入服务 | 将文本转换为数字以便相似度搜索 | 包含一个离线实现 |
| Redis | 可选的共享队列和取消支持 | 否 |
| Chroma | 可选的持久化向量搜索服务或本地存储 | 首次试用不需要；对持久化向量搜索有用 |
| 业务连接器 | 与订单系统或其他业务服务的连接 | 仅用于该业务功能 |

在某些可选连接不可用时，AskFlow 仍可继续接受请求。这并不证明每个已配置的功能都能正常工作；请验证你打算让客户使用的每一项功能。

## 合理的设置顺序

1. 在不使用外部连接的情况下让本地安装运行起来。
2. 登录，上传一个小型文本文档，并就它提一个问题。
3. 选择功能和客服访问权限。
4. 在添加重要记录之前规划存储和备份。
5. 一次一个地添加模型和业务连接。
6. 测试每个完整的客户旅程。
7. 让负责托管的人准备共享部署。

每一章都会说明要更改什么、何时生效、如何检查，以及恢复到先前设置涉及什么。参考章节会区分运营设置与保留或部分集成的设置。
